## Главное решение

PoC демонстрирует четыре механики: «Горячий шанс», персональную лигу, челленджи и «Сохрани рубли» на СТМ. Для пользователя рекомендатель выбирает одну механику; награда допускается только при положительной консервативной оценке дополнительной маржи и предотвращённого списания. Реальный эффект проверяется экспериментом, а не синтетическим прогнозом.
