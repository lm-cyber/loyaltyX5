# loyaltyX5 — «X5 Двор»

Материалы команды по игровой лояльности X5: персональные AI-миссии, приватный прогресс, экспериментальный «Двор-Lite», экономика наград, антифрод, симуляция и план причинного пилота.

## Начать отсюда

1. [Условия кейса](docs/01-case.md) — что требуется решить и какие есть ограничения.
2. [Последние уточнения команды](docs/08-correspondence-summary.md) — терминология, вредные категории и допустимый формат MVP.
3. [Итоговая концепция](docs/00-final-concept.md) — каноническое решение команды.
4. [Полный порядок чтения](docs/README.md) — маршруты для product, AI, analytics, risk и разработки.

## Главное решение

Ядро MVP — персональная безопасная миссия и приватный прогресс. Социальный «Двор-Lite» запускается только добровольно и в отдельной экспериментальной ветке. Денежная награда выдаётся лишь при положительной консервативной оценке дополнительной маржи. Реальный эффект проверяется store-cluster RCT, а не синтетическим прогнозом.
