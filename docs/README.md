## Происхождение данных

В документах намеренно разделены три уровня достоверности:

1. **Условия кейса** — требования и критерии, заданные кейсодателем.
2. **Командные предложения** — идеи из переписки; это не подтверждённые правила X5.
3. **Аналитические выводы** — интерпретации, расчёты и рекомендации на основе синтетических данных.

Особенно важно: значения `14 дней`, `10%`, `75%`, `20%`, `50%` и `12 месяцев` взяты из командного концепта. Их следует обозначать как допущения MVP, пока они не подтверждены X5 или пилотом.
