# Артефакты синтетической симуляции

Это компактная воспроизводимая часть исходного пакета `x5_all_data.zip`. Пакет моделирует сценарии на 1 000 и 10 000 синтетических пользователей и не является прогнозом поведения клиентов X5.

## Что сохранено

- [`code/`](code/) — два скрипта генерации и продолжения расчёта;
- [`config/`](config/) — сценарии и source ledger;
- [`results/`](results/) — reference metrics, 45×2 Monte Carlo, sensitivity и validation checks;
- [`figures/`](figures/) — три диагностических графика;
- [`reference-summaries/`](reference-summaries/) — `summary.json` прогонов 1k и 10k;
- [`DATA_DICTIONARY.csv`](DATA_DICTIONARY.csv), [`MANIFEST.csv`](MANIFEST.csv) и [`CAVEATS.csv`](CAVEATS.csv) — структура и ограничения исходного пакета; `MANIFEST.csv` перечисляет исходный ZIP целиком, включая намеренно не сохранённые здесь файлы;
- [`PACKAGE-README.md`](PACKAGE-README.md) — README, полученный вместе с архивом.

## Что удалено

Не сохранены полные синтетические таблицы пользователей, чеков, позиций, weekly outcomes и прочих сущностей. В распакованном виде они занимали около 158 МБ, в основном из-за `receipts.csv` и `items.csv`; эти данные воспроизводимы кодом и не нужны коллегам для чтения выводов. Не извлечены и копии исходных документов, уже находящиеся в `docs/`.

Исходный ZIP успешно прошёл `unzip -t`; его SHA-256 был `7ed12380dac3f727ca352080f6cc5f750cf92bc4918223fdeb9c2990909e99aa`.

## Важные ограничения запуска

Полученные скрипты жёстко используют путь `/mnt/data`, а `continue_x5.py` достраивает 10k-прогон и часть validation output. Для локального повторного запуска сначала нужно параметризовать input/output root и считать оба скрипта единой процедурой. Итоговыми результатами текущего пакета считаются файлы в [`results/`](results/).

Симуляционный каталог предшествует уточнению об алкоголе и табаке, поэтому отдельные harmful-category outcomes в нём отсутствуют. При следующем запуске их нужно добавить только как safety flags и guardrails, не создавая миссий на рост таких покупок.

Подробная интерпретация чисел находится в [`../06-simulation-summary.md`](../06-simulation-summary.md).
